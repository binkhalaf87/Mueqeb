|---|---------|---------|
| 1 ✅ | التأسيس والهوية والأدوار | Next.js + RTL، Supabase محلي، التسجيل والدخول، اختيار الدور، `profiles` و`requester_accounts` و`establishment_members` و`settings`، RLS، حماية المسارات، seed، الاختبارات. (دُمجت المرحلتان 0 و1 المقترحتان سابقاً) |

| 3 | الطلبات وآلة الحالات | جدول `orders` و`order_events`، دالة الانتقال الموحدة في الخادم، الطلب المباشر والطلب العام، المستندات في bucket خاص بروابط موقعة. |

| 5 | الدفع ودفتر الحسابات | واجهة `PaymentProvider` + Moyasar وضع الاختبار، ledger append-only بالهللة، escrow، الاستحقاق بعد الإنجاز، تسجيل الصرف اليدوي. |

| 7 | المحادثة | رسائل داخل الطلب، حجب الجوال والإيميل والروابط قبل الترسية. |
| 8 | التقييمات والإشعارات والإطلاق | تقييم المزوّد، إشعارات، النشر على Vercel، مراجعة أمنية شاملة. |
