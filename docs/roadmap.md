# خطة المراحل المقترحة

> مقترح أولي للنقاش. كل مرحلة تُنفذ فقط عند طلبها صراحةً.

| # | المرحلة | المحتوى |
|---|---------|---------|
| 0 | التأسيس | مشروع Next.js + TypeScript + Tailwind بواجهة RTL وخط IBM Plex Sans Arabic، إعداد Supabase محلياً (CLI)، ESLint/Prettier، Vitest + Playwright، CI أساسي، صفحة رئيسية مبدئية. |
| 1 | الهوية والأدوار | التسجيل والدخول (Supabase Auth)، جداول `profiles` و`establishments` وأعضاء المنشأة، `providers` مع حالة التوثيق، تقييد المسارات حسب الدور، RLS لكل جدول. |
| 2 | الكتالوج والإعدادات | جداول الجهات وأنواع الخدمات (حد أدنى للأتعاب ونطاق استرشادي)، جدول `settings` (العمولات، حد العروض، المهلة)، خدمات المزوّد بأسعار معلنة، لوحة إدارة لاعتماد المزوّدين. |
| 3 | الطلبات وآلة الحالات | جدول `orders` و`order_events`، دالة الانتقال الموحدة في الخادم، الطلب المباشر والطلب العام، المستندات في bucket خاص بروابط موقعة. |
| 4 | العروض المغلقة | تقديم العروض بقيودها (7 عروض، 24 ساعة، الحد الأدنى)، إخفاء بيانات العميل قبل الترسية، الترسية، انتهاء المهلة عبر cron. |
| 5 | الدفع ودفتر الحسابات | واجهة `PaymentProvider` + Moyasar وضع الاختبار، ledger append-only بالهللة، escrow، الاستحقاق بعد الإنجاز، تسجيل الصرف اليدوي. |
| 6 | التنفيذ والتسليم | خطوات التفويض الرسمية، `awaiting_client` → `in_progress` → `delivered`، التأكيد التلقائي بعد 3 أيام، النزاعات وحلّها من الإدارة. |
| 7 | المحادثة | رسائل داخل الطلب، حجب الجوال والإيميل والروابط قبل الترسية. |
| 8 | التقييمات والإشعارات والإطلاق | تقييم المزوّد، إشعارات، النشر على Vercel، مراجعة أمنية شاملة. |
